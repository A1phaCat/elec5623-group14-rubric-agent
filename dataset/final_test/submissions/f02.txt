# Shared battery logger: opening note

Laboratory demonstrators need to find why a portable teaching battery stops during a session. The logger records voltage once per minute. We want its event list to identify an interruption of more than two minutes; shorter gaps are outside the current scope. The intended users are demonstrators, rather than students estimating battery lifetime.

# Appendix A: file contract

Rows have timestamp, voltage and status columns. A replay reader uses the same interface as the device reader. In the first increment we checked malformed CSV headers. A later increment added gap grouping. We have not recorded the result of either check. The work plan says to test the grouping rule using a stored fixture after the interface is stable.

# Equipment inventory

The demonstration kit contains one rechargeable pack, a USB cable and a voltage divider. Packing instructions ask the custodian to count these items at the end of the week. This inventory describes the kit, not a validation dataset.

===PAGE 4===
# Discussion before measurements

The design is inexpensive and may make a missed sample easier to investigate. No run log or numeric results are available in this draft. A gap could arise from either an unplugged reader or the battery itself, so an interruption cannot be interpreted as battery failure without additional information. We use outage, gap and stop as informal names for a missing-data interval.
